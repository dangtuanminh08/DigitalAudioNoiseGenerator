## Digital Audio/Noise Generator! (DANG!) 📼
This project is a simple, ad-less Android app that uses Google's ExoPlayer to play audio files completely offline.\
Because this app was a quick solution, made for my own personal use there are features "missing" that I don't really find important (ex. artist names)\
I may update this project sparsley while I work on other things depending on what I need from the app.
Also, excuse my unserious commit comments. Again, this was for my own personal use so I'm really the only one who can understand my own commits haha

### Current Features ⚙️
- Cool animated Hello Kitty play/pause button!!!
- Pitch/Speed setting
- Notification controller
- Headphone gesture compatability
- Change names of/delete files
